# Команда «Со дна» — сайт-визитка

**Девиз:** «Погружайся в глубину — всплывай в легенды!»

Адаптивный сайт-визитка команды для участия во Всероссийском хакатоне «Волга.ТОП». Визуальная концепция вдохновлена предоставленными командой референсами: глубокие синие оттенки, космические водные текстуры, светящиеся сферы и лучи света.

## 2. Реализованное решение

Одностраничный сайт с разделами:
- Главная: название команды, эмблема, девиз и навигация.
- О команде: описание команды и мотивации участия.
- Участники: карточки с фото/аватаром, именем, ролью, учебной группой, навыками и необязательным контактом.
- Навыки команды: языки, технологии и инструменты.
- Проекты: выполненные работы и идеи.
- Контакты и подвал: ссылки команды, включая репозиторий.

Работающий интерактивный элемент: адаптивное мобильное меню. Карточки и контакты формируются из данных в `data.js`. Пустые контактные ссылки не отображаются.

**Перед отправкой:** замените демонстрационные значения в `data.js` реальными сведениями команды, добавьте общий контакт капитана и URL публичного репозитория. Фото и персональные контакты публикуйте только при наличии согласия участников. Вместо фотографии допускается аватар.

## 3. Технологический стек

- HTML5 — структура страницы.
- CSS3 — оформление, эффекты, адаптивная сетка и медиазапросы.
- JavaScript (ES6) — вывод структурированных данных и мобильная навигация.
- Nginx — статическая раздача файлов в контейнере.
- Docker и Docker Compose — контейнерный запуск.

Сторонние JS-библиотеки и сборщик не используются. Шрифт Manrope и Playfair Display загружаются из Google Fonts; при отсутствии сети браузер использует резервные системные шрифты.

## 5. Установка и запуск

### Требования
- Для обычного запуска: современный браузер.
- Для контейнерного запуска: Docker Engine и Docker Compose Plugin.

### Локально
Откройте `index.html` в браузере. Для локального сервера можно использовать расширение Live Server в Visual Studio Code.

### Docker
Из корня проекта выполните:

```bash
docker build -t so-dna-site .
docker run --rm -p 8080:80 so-dna-site
```

Откройте в браузере:

```text
http://localhost:8080
```

### Docker Compose
Из корня проекта выполните:

```bash
docker compose up --build -d
```

Сайт будет доступен по адресу:

```text
http://localhost:8080
```

Остановить:

```bash
docker compose down
```

## 7. Использование искусственного интеллекта

В ходе подготовки стартовой версии использовался ChatGPT (OpenAI). ИИ помог подготовить первоначальную структуру сайта, CSS-оформление, JavaScript-логику, адаптивные медиазапросы и черновую документацию. Визуальная тема и пользовательские изображения предоставлены участницей команды.

| Участник | Инструмент и модель | Задача | Что получено | Как проверено и доработано |
|---|---|---|---|---|
| Указать участника, работавшего с ИИ | ChatGPT, модель указана в интерфейсе сервиса | Черновая структура сайта и интерфейс | HTML/CSS/JS и документация | Команда должна проверить код, заполнить реальные данные, протестировать в целевых браузерах и самостоятельно доработать |

**Содержание запросов:** создание сайта-визитки команды «Со дна» по заданию «Волга.ТОП», адаптивная версия для ПК и мобильных устройств, морская/космическая эстетика по предоставленным референсам, редактируемые карточки участников и проектов.

**Созданные с помощью ИИ элементы:** стартовые версии `index.html`, `styles.css`, `data.js`, `script.js`, `Dockerfile`, `docker-compose.yml` и этого README.

**Ограничения и самостоятельная доработка:** реальные сведения о команде, подтверждённые навыки, проекты, контакты, GitVerse-профили и окончательное тестирование должны быть внесены и проверены участниками. Каждый участник должен понимать и уметь объяснить код и решения, относящиеся к его вкладу.

**Архив:** `ai-sessions.zip`. В архив включён журнал-сводка этой сессии. Для полного соответствия требованиям приложения 1 добавьте экспорт диалога/снимки экрана существенных ИИ-сессий всех участников и удалите конфиденциальные данные перед публикацией.

## 8. Демонстрация

- Скриншоты: добавьте актуальные снимки сайта для ширин 360 px, 768 px и 1440 px.
- Видео команды (1–3 минуты): добавьте доступную ссылку.
- Ссылка на развёрнутый сайт: добавьте после публикации на российском облачном сервисе или сервере команды.

## 9. Дополнительные задания

### Контейнеризация
Реализована через `Dockerfile`. Образ Nginx раздаёт статические файлы на порту 80 контейнера. Локальный запуск опубликован на порту 8080.

### Compose
Реализован через `docker-compose.yml`; запуск одной командой:

```bash
docker compose up --build -d
```

### Развёртывание и HTTPS
Пока не настроены. Для получения баллов за развёртывание разместите сайт на российском облачном сервисе или собственном физическом сервере, укажите внешний URL и настройте действующий HTTPS-сертификат с перенаправлением HTTP на HTTPS. Не добавляйте в репозиторий секреты и ключи.
